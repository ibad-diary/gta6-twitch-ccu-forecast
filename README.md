Forecasts GTA VI's launch-day Twitch viewers hour by hour: for each of hours 2..24 (UTC) of 19 November 2026, five quantiles of the concurrent viewers in the Grand Theft Auto VI Twitch category. The model fits, at runtime, log(viewers_h / viewers_1) = a_h + b_h * log(hour-1 print) over past rolling-midnight game launches (the case's own comparables), with the first hour clamped to the fitted range and a residual-based spread. Validated on the four practice launches at a mean pinball loss of 0.159, against the house baseline's 0.387.

## Run it

```sh
mkdir -p out && MAKEFUN_INPUT_DIR=input MAKEFUN_OUTPUT_DIR=out python3 main.py
```
